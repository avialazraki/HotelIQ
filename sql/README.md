# HotelIQ SQL Analysis

This folder contains PostgreSQL scripts used in the HotelIQ project.

## Database
- Database: hoteliq_db
- Main table: public.bookings
- Records analyzed: 118,564

## SQL Analysis
- Hotel booking performance
- Cancellation rates
- Monthly booking and cancellation trends
- Market segment analysis
- Booking lead time analysis
- SQL views and JOIN operations

## Tools
- PostgreSQL 18
- pgAdmin
