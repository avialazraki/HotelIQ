# HotelIQ Power BI Dashboard

This folder contains the interactive Power BI dashboard
developed for the HotelIQ project.

## Dashboard Pages

### 1. Executive Overview
- Total bookings and cancellation rate
- Estimated booking value
- City Hotel vs Resort Hotel comparison
- Monthly booking and cancellation trends

### 2. Cancellation Drivers
- Cancellation rates by market segment
- Booking lead time analysis
- Cancellation volumes
- Interactive hotel and market segment filters

### 3. Machine Learning Insights
- Random Forest model performance KPIs
- Confusion Matrix
- Top 10 feature importances
- Business insights and recommendations

## Main Dashboard File

HotelIQ_Interactive_Dashboard.pbix

## Tool
Microsoft Power BI Desktop
